This is my personal portfolio, showcasing real projects — SpicyEat, Ticket
Booking, Trip Meter, Intern Flow, and Recruit Flow — along with my
experience, technical expertise, and GitHub activity.

The website focuses on:

# ▶ Run Locally

### Method 1

Open `index.html` directly in a browser.

### Method 2 — VS Code

Install the **Live Server** extension, then right-click `index.html` →
**Open with Live Server**.

### Method 3 — Python

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`.

---

# 🌐 Deployment

## GitHub Pages

```bash
git push origin main
```

Then enable **Settings → Pages → Deploy from main branch**.

## Netlify / Vercel

Connect the GitHub repository and deploy — no build step required.
